# homebrew-aiquota

Homebrew tap for [aiquota](https://github.com/anujpatel06/aiquota) — see how
much of every AI subscription you've used, in one place.

```bash
brew install anujpatel06/aiquota/aiquota
aiquota install-widget
```

Then click **＋ Add an AI account** in the widget and sign in.

The widgets need a host app:

```bash
brew install --cask swiftbar    # menu bar
brew install --cask ubersicht   # desktop
```

---

Formula tracks the [PyPI release](https://pypi.org/project/aiquota/). Issues
and PRs belong on the [main repo](https://github.com/anujpatel06/aiquota).
